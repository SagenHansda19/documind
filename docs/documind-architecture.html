04. Architecture & Pipeline

Chunks, Embeddings & The Enterprise Tech Stack

pgvector · LangChain4j · Spring Boot 3.3

Understanding how text relates to vectors, and why Spring Boot beats Python scripts for production RAG.

Binding Pipeline

Chunk-to-Embedding Binding

01. THE TEXT CHUNK
Physical Raw Text

The physical block of raw text parsed from your PDF (e.g., your resume's education or project description), sliced into overlapping segments (800 chars, 150 overlap) so context is never severed.

02. THE EMBEDDING VECTOR
768-D Float Coordinates

The 768-dimensional float array generated immediately for that specific chunk, acting as its semantic coordinate in PostgreSQL (pgvector).

03. THE DATABASE LINK
doc_embeddings Table

Each row in doc_embeddings pairs one exact text chunk with its vector coordinate and metadata (file_name), allowing pgvector to retrieve the matching text instantly during semantic queries. 

-- PostgreSQL pgvector table binding
CREATE TABLE doc_embeddings (
  embedding_id UUID PRIMARY KEY,
  text TEXT NOT NULL,                     -- Bound raw chunk text
  embedding vector(768) NOT NULL,        -- 768-d semantic coordinate
  metadata JSONB                         -- {"file_name": "resume.pdf", "chunk_index": 0}
);
-- Fast nearest-neighbor index using Cosine Distance (<=>)
CREATE INDEX ON doc_embeddings USING hnsw (embedding vector_cosine_ops);
Retrieval Theory

Semantic Vector Proximity vs. Keyword Lookups

Brittle: Traditional Keyword Search

SQL LIKE '%term%' or full-text inverted indexes require exact lexical spelling.

  • Searching "salary" completely misses documents that say "compensation".
  • Fails on user rephrasings, colloquialisms, and conversational multi-turn context.
  • Zero understanding of conceptual hierarchy or contextual meaning.
Resilient: pgvector Semantic Search

Computes continuous cosine distance (<=>) directly across 768 dimensions.

  • "vacation policy" matches "accrue 20 days paid leave" with 0 shared words.
  • Bridges user intent with technical/corporate document terminology.
  • Scores matches by cosine similarity (1 - distance) with minScore=0.35 thresholding.
Tech Stack Rationale

Java Enterprise vs. Python / LangChain / LangGraph

LangChain4j vs. Python LangChain

While Python popularised AI prototyping, LangChain4j brings these exact RAG abstractions (splitters, stores, memory) to Java:

  • Compile-time Type Safety: Prevents dimension mismatch bugs and unhandled runtime exceptions.
  • High-Throughput Concurrency: Handled by JVM thread pools without Python GIL bottlenecks.
  • Enterprise Connection Pooling: Native HikariCP integration with PostgreSQL.
  • Production Artifact: Single executable .jar without fragile virtual environments.
Why Not LangGraph?

LangGraph is designed for complex, cyclical multi-agent loops (where AI agents debate or branch conditionally):

  • Linear & Predictable: For a RAG knowledge assistant, a clean, linear enterprise pipeline (RagService) combined with Spring session memory is robust, predictable, and fully sufficient.
  • Zero Latency Overhead: Eliminates iterative loop delays and unpredictable token burns.
  • Auditable Memory: MessageWindowChatMemory provides a clean, per-session sliding conversation window.
Structural
Proxy Pattern
ResilientFailoverChatModel wraps the ChatLanguageModel interface. It intercepts HTTP 429 rate limits and 503 outages, transparently routing to a secondary provider with zero downtime. 
public class ResilientFailoverChatModel
    implements ChatLanguageModel {

  private final ChatLanguageModel primary;   // Groq
  private final ChatLanguageModel secondary; // Gemini

  @Override
  public Response<AiMessage> generate(
      List<ChatMessage> messages) {
    try {
      return primary.generate(messages);
    } catch (Exception e) {
      log.warn("Failover: {}", e.getMessage());
      return secondary.generate(messages);
    }
  }
}
Interview: Lightweight proxy vs heavyweight Circuit Breaker — sub-ms route switching without thread starvation.
Behavioral
Strategy Pattern
Encapsulates interchangeable AI provider algorithms. Switch at runtime via ai.provider=auto|groq|gemini without restarting the app. 
@Bean
public ChatLanguageModel chatLanguageModel() {
  if ("groq".equalsIgnoreCase(provider))
    return buildGroqChatModel(groqKey);
  if ("gemini".equalsIgnoreCase(provider))
    return buildGeminiChatModel(geminiKey);

  // 'auto': Groq primary + Gemini failover
  return new ResilientFailoverChatModel(
    buildGroqChatModel(groqKey),
    buildGeminiChatModel(geminiKey)
  );
}
Interview: Ops teams can throttle around regional outages by modifying AI_PROVIDER env var in containers.

Behavioral
Chain of Responsibility
3-stage key resolution pipeline traverses Spring Property → System Env → .env file until credentials are found. Includes self-healing AQ. prefix restoration. 
Stage 1: @Value("${gemini.api.key}")
   ↓ (if empty)
Stage 2: System.getenv("GEMINI_API_KEY")

Mathematical
Matryoshka Representation Learning
gemini-embedding-001 natively outputs 3072-d vectors. PostgreSQL's vector(768) schema requires dimension alignment. MRL-trained models ensure early prefixes (first 768 dims) capture primary semantic variance with <1% retrieval degradation. 
// Dimension Lock
GoogleAiEmbeddingModel.builder()
  .outputDimensionality(768)  // MRL truncation
  .build();

// Cosine distance in pgvector:
// D(u,v) = 1 - (u·v) / (||u||₂ · ||v||₂)
// Operator: <=> (HNSW indexed)
Interview: Without .outputDimensionality(768), inserting 3072-d vectors into vector(768) causes immediate SQL runtime crashes.
Data Pipeline
Chunking & Retrieval Dedup
300-char chunks (~45 words) fractured project descriptions across 3+ segments. Upgraded to recursive(800, 150) to preserve coherent blocks. Retrieval uses seenTexts.add() deduplication over a maxResults=12 window, then caps to top-8. 
// Ingestion chunking
DocumentSplitters.recursive(800, 150);

// Retrieval dedup
Set<String> seenTexts = new HashSet<>();
for (EmbeddingMatch match : rawMatches) {
  if (seenTexts.add(match.text().trim()))
    matches.add(match);
}
// Cap: top 8 distinct chunks
Interview: On re-upload, prior file chunks are purged via DELETE WHERE metadata->>'file_name' to prevent vector table pollution.

AiConfig.java — Key Resolution 
private String resolveGeminiApiKey() {
    String key = geminiApiKey;
    if (key == null || key.isBlank())
        key = System.getenv("GEMINI_API_KEY");
    if (key == null || key.isBlank())
        key = extractFromEnvFile("GEMINI_API_KEY");
    if (key != null && !key.isBlank()) {
        key = key.trim()
                 .replace("\"", "")
                 .replace("'", "");
        if (!key.startsWith("AQ.") &&
            !key.startsWith("AIza"))
            key = "AQ." + key;
    }
    return key;
}

06 — Troubleshooting

Bug Fixes & Gotchas

Critical issues encountered during development and their exact resolutions.

Runtime Failure: HTTP 400 INVALID_ARGUMENT
java.lang.RuntimeException: INVALID_ARGUMENT (code 400) API key not valid.
Thrown inside GoogleAiEmbeddingModel.embed() when executing POST models/{model}:embedContent.
1. The 'AQ.' Prefix Truncation
Google AI Studio keys begin with AQ. prefix. Stripping it invalidates the cryptographic hash at Google's API gateway → instant 400. 
❌ your_key_without_prefix...
✔  AQ.your_key_with_prefix...
2. Lazy Initialization Illusion
Spring Boot starts fine because GoogleAiGeminiChatModel.builder().build() is lazy — no network handshake on startup. The crash happens on first embed() call, not at boot time. Misleading if you only check startup logs.
3. Vector Dimension Mismatch
gemini-embedding-001 defaults to 3072 dimensions. pgvector table is vector(768). Without .outputDimensionality(768), DB insertions crash with dimension mismatch errors.
4. Self-Healing Key Resolution
resolveGeminiApiKey() and resolveGroqApiKey() check OS Env → Spring Properties → local .env file. Auto-restores AQ. prefix if missing. Tolerates quoted values and whitespace.
5. Groq 429/503 Failover
Groq free tier enforces aggressive rate limits. ResilientFailoverChatModel catches any exception from the primary provider and transparently routes to Gemini Flash. Controlled via ai.provider=auto|groq|gemini.
