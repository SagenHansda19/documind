Key Bug Fixes & Troubleshooting

Analysis of the HTTP 400 runtime failure and exact resolution details.

⚠️
The Runtime Failure: HTTP 400 INVALID_ARGUMENT
java.lang.RuntimeException: INVALID_ARGUMENT (code 400) API key not valid. Please pass a valid API key. Thrown inside GoogleAiEmbeddingModel.embed() when executing POST models/{model}:embedContent.

1. The 'AQ.' Prefix Truncation

Google AI Studio keys modern format begins with an explicit AQ. prefix. Stripping this prefix invalidates the cryptographic hash check at Google's Envoy API gateway, resulting in an immediate 400 INVALID_ARGUMENT.

❌ Ab8RN6KbOmfv5oixYryOoOvt... (Truncated)
✔️ AQ.Ab8RN6KbOmfv5oixYryOoOvt... (Valid)

2. Lazy Initialization Illusion

Spring Boot starts successfully because GoogleAiGeminiChatModel.builder().build() is entirely lazy—it configures Retrofit without making any network handshake on startup.

In RAG, askQuestion() embeds the question on line 72 before calling generate. The app failed at embedding before the chat model was ever invoked.

3. Vector Dimension Alignment

Google's gemini-embedding-001 defaults to 3072 dimensions. Because pgvector in PostgreSQL is initialized with vector(768), omitting dimension control results in database insertion crashes.

Fix: Explicitly invoke .outputDimensionality(768) on the embedding model builder.

4. Self-Healing Key Resolution

Instead of fragile static strings, AiConfig.java implements resolveApiKey(), which trims whitespace, strips quotes, and auto-restores AQ. if accidentally omitted.

Guarantees immediate zero-downtime tolerance for human configuration mistakes.

AiConfig.java • Key Normalization 
// Restores 'AQ.' prefix if accidentally truncated
private String resolveApiKey() {
    if (apiKey == null || apiKey.isBlank()) {
        return "";
    }
    String key = apiKey.trim().replace("\"", "").replace("'", "");
    if (!key.startsWith("AQ.") && !key.startsWith("AIza")) {
        key = "AQ." + key;
    }
    return key;
}
AiConfig.java • 768-D Dimension Lock 
@Bean
public EmbeddingModel embeddingModel() {
    return GoogleAiEmbeddingModel.builder()
            .apiKey(resolveApiKey())
            .modelName(embeddingModelName)
            .outputDimensionality(768) // Matches pgvector vector(768)
            .build();
}

API Reference

REST Endpoints Specification

Full contract for Document Ingestion and Context-Grounded Querying.

POST /api/rag/ingest
Chunks input document into 300-token segments with 50-token overlap, calculates 768-d embeddings, and inserts them into PostgreSQL.
cURL Invocation 
curl -X POST http://localhost:8080/api/rag/ingest \
  -H "Content-Type: application/json" \
  -d '{"text": "DocuMind is an enterprise knowledge assistant developed using Spring Boot, PostgreSQL with pgvector, and Google Gemini."}'
Response (200 OK) 
Successfully ingested 1 text chunks into pgvector!
POST /api/rag/ask
Converts query to vector representation, searches pgvector for top-3 relevant segments (score ≥ 0.6), and generates a strictly grounded answer.
